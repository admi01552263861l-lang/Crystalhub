Crystal Hub - Fabric Client Mod
================================

المشروع يستهدف Minecraft Java 26.1.2 مع Fabric.

التصميم:
- نافذة وسط الشاشة بطابع زجاجي داكن.
- شريط جانبي واضح مع تمييز التبويب النشط.
- ألوان أزرق وبنفسجي وبطاقات داخلية.
- Right Ctrl لفتح/إغلاق القائمة.
- القائمة لا توقف اللعبة.

إخراج JAR تلقائياً عبر GitHub:
1) ارفع كل محتويات هذا المجلد إلى مستودع GitHub جديد، بما فيها مجلد .github.
2) افتح تبويب Actions في المستودع.
3) اختر Build Crystal Hub ثم Run workflow، أو ادفع Commit جديداً.
4) بعد نجاح البناء افتح نتيجة التشغيل وانزل إلى Artifacts.
5) نزّل crystal-hub-1.0.0.zip، ثم استخرج ملف JAR وضعه في مجلد mods.

تنبيه: لم يتم تشغيل عملية Gradle build أو اختبار المود فعلياً في هذه البيئة. قد نحتاج تعديل توافق API إذا أظهر GitHub خطأ بناء. يلزم Fabric Loader وFabric API المطابقان لإصدار Minecraft 26.1.2، وJava 25.
